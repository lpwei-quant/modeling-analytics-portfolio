# 农业种植规划：收益与风险的情景分析

**2026 年 8 月进行的建模训练，使用 2024 年全国大学生数学建模竞赛 C 题。** 本项目不代表 2024 年参赛经历或获奖经历。题目来自[竞赛官方网站的 2024 年赛题页](https://www.mcm.edu.cn/html_cn/node/a0c1fb5c31d43551f08cd8ad16870444.html)。

面对 54 个地块、41 种作物、1213 亩耕地，研究怎样安排 2024—2030 年的种植面积，并在产量、需求、价格和成本不确定时评价收益与下行风险。这个公开包重点展示从确定性模型到不确定性评价的研究过程，以及一次没有获得预期提升的模型扩展。

## 主要结果

冻结 Q2 方案和 Q3 方案在**同一组 3000 条 Q3 相关情景路径**上进行固定方案评价；超产部分按基准价 50% 出售。表中金额是 2024—2030 年累计名义利润，不是年利润，也不是实际经营收入。

| 固定方案 | 模拟平均利润 / 元 | 下尾 CVaR90 / 元 |
|---|---:|---:|
| Q2 冻结方案 | 69,651,139.2433 | 67,553,632.4148 |
| Q3 扩展方案 | 69,578,124.6787 | 67,476,465.2705 |

这里的下尾 CVaR90 是最差 10% 路径的平均利润，数值越高越好。**Q3 没有超过 Q2**：平均利润低约 73,014.56 元，下尾 CVaR 低约 77,167.14 元；同路径比较中 Q2 在 2998/3000 条路径上利润更高。这只是已设定模拟环境中的结果，不能推出真实农业经营中的普遍优劣。

原研究的主优化使用 60 个 LHS 情景；3000 条 Monte Carlo 路径用于冻结后的样本外评价，不参与方案求解。Q2 独立环境下的历史评价不能直接当作 Q3 相关环境下的对照，本包的结果表与配对利润都来自同一个 Q3 环境。

## 研究方法与判断

1. **Q1：确定性基线。** 用地块、作物、年份和季次表示种植面积，结合适种性、容量、水浇地制度、相邻种植机会轮作和滚动三年豆类面积要求建立混合整数规划。销量基值由 2023 年理论产量代理，价格取附件区间中点。
2. **Q2：独立不确定性与收益下尾。** 对需求、产量和价格路径引入显式随机假设，用固定情景集求解；最终保留冻结候选和收益/CVaR 双上界评价，未把未完成的 θ 前沿当成最终成果。
3. **Q3：相关环境与稀疏价格需求交互。** 引入共同气象、市场与投入因子，并加入自身价格、组内替代及组级互补弹性。Q3 也调整了部分价格/成本增长的边际扰动，因此结果不能归因为“只改变相关性”。
4. **统一评价。** 冻结种植计划，在同一组相关路径上比较利润分布，保留负结果。36 行敏感性表覆盖 3 种依赖强度 × 3 种弹性强度 × 2 种超产规则 × 2 个方案；每个方案在各设置中保持不变。

共同因子载荷、弹性点值、需求代理和新增窄区间都属于 **Assumed / Decision**。它们没有通过历史价格序列估计，不能称为经验相关系数。原始附件字段属于 **Observed**；清洗后的计算基础和方案属于 **Derived**；3000 路径利润属于 **Simulated**。

## 可复现内容

从仓库根目录运行：

```bash
python projects/agriculture-2024/scripts/reproduce.py
```

脚本从本项目自己的 `src/` 与 `data/` 加载输入，重新生成 3000 条相关路径，重算两方案利润，逐路径比对冻结利润，并检查农业可行性、输入哈希及敏感性表结构。不会调用优化器。默认报告写到本项目 `.reproduction/verification.json`。

本次实际运行证据见 [evidence/verification.json](evidence/verification.json)：两方案 6000 个路径利润值与冻结文件的最大绝对误差约 **5.22×10⁻⁸ 元**；农业可行性检查均通过。情景数组的二进制 SHA-256 与历史记录不同，所以本包报告的是数值复现通过，没有宣称历史二进制逐字节重现。

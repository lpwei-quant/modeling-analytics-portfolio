# 数据来源、获取与输入边界

官方来源是[2024 年高教社杯全国大学生数学建模竞赛赛题页](https://www.mcm.edu.cn/html_cn/node/a0c1fb5c31d43551f08cd8ad16870444.html)，页内提供 `CUMCM2024Problems.zip`。在 C 题目录取得题目 PDF、附件 1 和附件 2。题名为《农作物的种植策略》。公开页于 2026-09-19 核实；本包没有重新下载官方压缩包进行字节比对。

本包不附带官方原始工作簿或题目 PDF。原题与原始附件权利归其权利人，公开访问不授予这些第三方材料新的使用许可。`data/input_basis.json` 是为了复算而保留的规范化必要字段及计算基础，有明确来源，不能标为自行采集的真实经营数据。

## 可选：从附件核对规范化基础

在本项目下创建 `.local-inputs/`，将附件放入以下位置；该目录由项目 `.gitignore` 排除。

```text
.local-inputs/附件1.xlsx
.local-inputs/附件2.xlsx
```

在本项目目录运行：

```bash
python scripts/prepare_inputs.py
```

也可以用 `--attachment-1` 和 `--attachment-2` 指向其他合法取得的本地文件。脚本只读工作簿，检查 SHA-256，复用冻结的读取与字段映射函数，并按作物×季次累加 2023 年“面积×亩产”重建需求代理。全部字段与公开基础一致后，输出副本到 `.reproduction/input_basis_rebuilt.json`。默认固定方案重算直接读取规范化基础，不依赖原附件或原私人目录。

## 哪些是数据，哪些是假设

| 分类 | 本项目实例 | 解释边界 |
|---|---|---|
| Observed | 题面提供的地块面积、作物类型、2023 种植行、亩产、成本和价格区间 | 指官方题目附件中给出的记录，不表示本项目实地采集 |
| Derived | 清洗后的索引、理论产量、区间中点、方案面积、模拟汇总 | 依赖来源字段、计算规则与冻结方案 |
| Decision / Assumed | 产量作为销量代理、价格中点代表价、整块水浇地制度、滚动豆类累计面积近似 | 模型选择，不是附件额外提供的事实 |
| Assumed / Simulated | 共同因子载荷、弹性点值、随机路径与路径利润 | 没有经验估计相关性，不能写成真实经营效果 |
| Uncertain | 真实需求、子地块空间轮作覆盖、未来参数稳定性 | 当前材料无法直接验证 |

销量代理、额外价格/成本扰动和管理限制会影响结论。仅核对代码不能消除这些外推边界。

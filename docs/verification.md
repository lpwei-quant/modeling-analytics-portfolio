## 展示与发布检查

- 四幅展示图由公开冻结 CSV 生成，输入输出哈希见 [assets/manifest.json](../assets/manifest.json)。单位转换仅服务阅读，不改变数值含义。
- 六页作品集检查 PDF 页数、文字提取和全部页面实际渲染，检查中文显示、裁切、图表与文字重叠。
- 两条项目经历分别提供短版和详细版，详细版均少于 1000 字；Markdown 与 JSON 正文一致。
- 原始赛题与附件通过官方来源获取，并使用本地冻结输入的哈希校验；不把未进行的官方 ZIP 重新下载比对称为已完成。
- 公开提交采用明确文件清单；私人会话、凭据、身份敏感材料、原始工作簿、环境和本地临时文件排除在外。

内容静态检查入口：`python scripts/check_portfolio.py`。该检查覆盖公开链接、文件哈希、PDF 页数、文案一致性和文件清单；不替代上面的数值复现及实际页面阅读。

### 短版（191字）

参与2026年全国大学生数学建模竞赛C题，围绕预测偏差下的微网购电、储能与合同调整开展策略分析。我审查建模假设，针对初始充放电表述提出质疑并推动重做第一问，汇总外部意见与论文。在334日历史回放中，团队反馈策略较固定场景调度现金费用低3.59%，结合期末库存解释差异。项目以Python计算、Excel结果表和图表交付；AI承担大量代码与计算，个人侧重方案审查、研究推进和成果整理。

我主要负责建模方案审查、研究推进与成果整理：针对初始充放电表述提出质疑，推动重新研究第一问；参与重要假设与修订方案的讨论，汇总转交的外部意见，将核实后的修改整合到论文与支撑材料。团队最终采用状态增量线性规划，在题给预测日获得35126.95元最优费用，并通过显式互斥模型对照核查结果。

团队在2025年2月至12月共334日连续回放中，比较固定场景调度、日内反馈与合同调整。反馈策略现金费用为1377.60万元，较固定场景调度低3.59%；两者期末库存分别为8264.39和8221.73千瓦时。进一步采用预报更新与分段改约后，现金费用减少27.29万元，期末库存为8303.87千瓦时。上述结果是既定量测条件下的回顾性策略比较，不能直接解释为实际运营收益或因果效果。

项目形成Python计算程序、Excel结果表、图表与完整论文。我参与成果核对与最终人工审阅；AI实质参与模型草案，并承担大量程序实现、求解、绘图和文稿辅助，个人贡献集中于问题审查、取舍讨论、研究推进和成果整理。

## 农业种植规划：收益与风险的情景分析

时间：2026-08 至 2026-08  
角色：建模方案审查、研究推进与成果整理  
作品链接：[农业种植规划：收益与风险的情景分析](https://github.com/lpwei-quant/modeling-analytics-portfolio/tree/main/projects/agriculture-2024)

### 短版（199字）

2026年8月以2024年国赛C题开展训练，围绕54个地块、41种作物的种植方案比较收益与风险。我参与模型和假设选择审查、分阶段研究采纳及结果冻结，推动论文与图表对齐结果证据。采用60个优化情景构建方案，在3000条模拟样本外路径上评价；相关风险扩展未超过原基准，因此保留证据支持的基准方案，并分析共同冲击对尾部风险的影响。项目使用Python与Excel结果表，AI承担大量代码、计算和文稿辅助。

### 长版（606字）

2026年8月，以2024年全国大学生数学建模竞赛C题开展农业种植规划训练，未作为2024年参赛经历。项目覆盖54个地块、41种作物和1213亩耕地，围绕销量、亩产、成本及价格的不确定性，比较种植方案的收益与下行风险，形成确定性规划、随机情景评价和相关风险分析三层研究。

我主要负责建模方案审查、研究推进与成果整理：参与模型与假设选择讨论，按阶段审查研究结果并确认采纳范围，推动保留冻结版本；整理有来源的章节和图表，使论文中的数字、指标定义与结论对应已保存的结果，避免把复杂模型本身当作改进证据。

采用60个优化情景构建随机规划方案，以平均利润和90%下尾CVaR衡量收益及较差情形下的表现，再用3000条模拟样本外路径评价固定方案。在统一的相关风险环境及超产半价销售规则下，原基准方案平均利润为6965.11万元、下尾CVaR为6755.36万元；相关风险扩展方案分别为6957.81万元和6747.65万元，均未超过基准。因此保留原基准用于方案推荐，将扩展模型用于识别共同冲击增强时的尾部风险。

这些路径由设定的随机模型生成，结果是2024—2030年规划期的模拟名义利润，不是已实现收益或真实未来观测。项目输出Python程序、Excel结果表、对比图和论文；AI实质参与模型草案，并承担大量代码、计算与文稿辅助。我的贡献集中于假设审查、阶段取舍、证据整理和结论表达，强调按同一评价口径决定是否采用更复杂的方案。
